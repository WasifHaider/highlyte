# UI Polish: Custom Selects, Motion, Loading States Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the native dropdowns and colour inputs with styled components, fix the edit panel's clipped right column, add smooth transitions to every section, drawer and menu, and add proper loading states, all without changing behaviour.

**Architecture:** Two small, accessible, token-styled components, `UiSelect.vue` and `UiColorField.vue`, replace every `<select class="select">` and `<input type="color">`. Motion comes from shared CSS transition classes in `style.css`, used through Vue `<Transition>`/`<TransitionGroup>`, with global `prefers-reduced-motion` support. Loading states come from a shared skeleton primitive and a button spinner.

**Tech Stack:** Vue 3 (`<script setup>`), Pinia, Vite, plain CSS. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-27-ui-redesign-design.md` (tokens and direction) plus the user's request of 2026-09-27: "proper loading states and some smooth transitions of everything, every section, drawer … make this dropdown a bit more beautiful everywhere and it is fading on right … use vuetify components if necessary or use css your choice".

## Decisions

| Question | Decision |
|---|---|
| Vuetify or CSS | **CSS and our own components.** Vuetify brings its own design language, a big CSS reset and around 300 KB. It would fight the approved tokens and add a second styling system. The two custom components below cover the need. |
| "Fading on right" | In the edit panel, the right column (the Captions select and the Accent field) is clipped. The grid uses `1fr 1fr` and the selects keep their intrinsic width, so they overflow the 320px panel. Fix: `minmax(0, 1fr)` columns and full-width controls. |
| Colour input | Native pickers can't be styled. `UiColorField` shows a swatch button that opens a small popover with 8 preset colours (the house palette below) and a "Custom…" row that opens the native picker. |
| Motion | 120–200ms ease-out fades and short slides, as the design system asks ("subtle only … no bouncing"). Everything is off under `prefers-reduced-motion: reduce`. |

          :class="{ active: i === active, selected: opt.value === modelValue, disabled: opt.disabled }"
          :aria-selected="opt.value === modelValue"
          :aria-disabled="!!opt.disabled"
          @mouseenter="!opt.disabled && (active = i)"
          @mousedown.prevent
          @click="choose(opt)"
        >
          <span>{{ opt.label }}</span>
          <svg v-if="opt.value === modelValue" width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2.5" aria-hidden="true"><path d="M20 6 9 17l-5-5"/></svg>
        </li>

  </div>

<script setup>
import { computed, nextTick, onBeforeUnmount, ref } from 'vue'

const props = defineProps({
  modelValue: { type: [String, Number], default: null },
  options: { type: Array, required: true }, // [{ value, label, disabled? }]
  disabled: { type: Boolean, default: false },
  ariaLabel: { type: String, default: undefined },
  id: { type: String, default: undefined },
})
const emit = defineEmits(['update:modelValue'])

const uid = Math.random().toString(36).slice(2, 8)
const root = ref(null)
const trigger = ref(null)
const list = ref(null)
const open = ref(false)
const openUp = ref(false)
const active = ref(-1)

const selected = computed(() => props.options.find(o => o.value === props.modelValue))
const optionId = i => `ui-select-${uid}-${i}`
const activeId = computed(() => (active.value >= 0 ? optionId(active.value) : undefined))

function onOutside(e) {
  if (root.value && !root.value.contains(e.target)) close(false)
}

async function show() {
  if (props.disabled || open.value) return
  // Open upwards when there isn't room below (e.g. near the bottom of the panel).
  const rect = trigger.value.getBoundingClientRect()
  openUp.value = window.innerHeight - rect.bottom < 240 && rect.top > 240
  const idx = props.options.findIndex(o => o.value === props.modelValue)
  active.value = idx >= 0 ? idx : firstEnabled(0, 1)
  open.value = true
  document.addEventListener('pointerdown', onOutside, true)
  await nextTick()
  list.value?.focus()
  list.value?.querySelector('.active')?.scrollIntoView({ block: 'nearest' })
}

function close(refocus = true) {
  if (!open.value) return
  open.value = false
  document.removeEventListener('pointerdown', onOutside, true)
  if (refocus) trigger.value?.focus()
}

function toggle() {
  open.value ? close() : show()
}

function choose(opt) {
  if (opt.disabled) return
  if (opt.value !== props.modelValue) emit('update:modelValue', opt.value)
  close()
}

function firstEnabled(from, step) {
  for (let i = from; i >= 0 && i < props.options.length; i += step) {
    if (!props.options[i].disabled) return i
  }
  return -1
}

function move(step) {
  const next = firstEnabled(active.value + step, step)
  if (next !== -1) active.value = next
  nextTick(() => list.value?.querySelector('.active')?.scrollIntoView({ block: 'nearest' }))
}

function onTriggerKey(e) {
  if (['ArrowDown', 'ArrowUp', 'Enter', ' '].includes(e.key)) {
    e.preventDefault()
    show()
  }
}

function onListKey(e) {
  if (e.key === 'ArrowDown') { e.preventDefault(); move(1) }
  else if (e.key === 'ArrowUp') { e.preventDefault(); move(-1) }
  else if (e.key === 'Home') { e.preventDefault(); active.value = firstEnabled(0, 1) }
  else if (e.key === 'End') { e.preventDefault(); active.value = firstEnabled(props.options.length - 1, -1) }
  else if (e.key === 'Enter' || e.key === ' ') {
    e.preventDefault()
    const opt = props.options[active.value]
    if (opt) choose(opt)
  } else if (e.key === 'Escape') { e.preventDefault(); e.stopPropagation(); close() }
  else if (e.key === 'Tab') close(false)
}

onBeforeUnmount(() => document.removeEventListener('pointerdown', onOutside, true))
</script>
